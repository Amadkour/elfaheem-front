# testimonials.json

An array shown in the "What learners say" section. The section is rendered only when the array is
non-empty, so it ships as `[]`. Add real, permitted quotes only. Shape:

```json
[
  {
    "name": "Full name",
    "role_ar": "طالب ثانوي",
    "role_en": "High-school student",
    "quote_ar": "...",
    "quote_en": "..."
  }
]
```
