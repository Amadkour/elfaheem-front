# Home screens and badges

Moved verbatim from the root `CLAUDE.md` (which keeps a short summary and the rules a session must never miss). Keep this file in step with the code.

**Home screens and badges** — Every role's home is built from `lib/design/home_kit.dart` (`HomeHeader`, `HomeHeroCard`, `HomeActionGrid`, `HomeAgenda`, `HomeTodoCard`, …; the header comment lists the parts and the 8·16·24·32 rhythm). The student, teacher and org-member homes are kept short and calm on purpose (D-102): a light greeting header, ONE live / next-up card (card surface + hairline; its red dot and Join are the page's one strong accent), "Needs you" as ONE slim row of outlined pills (`HomeStatStrip`; zero counts hidden, scrolls sideways), Today, courses as ONE `HomeCourseSummary` card (3 lines with progress + "All courses (n)"; the teacher's students · rating · earnings head it and open analytics; the full cards live on the courses tab), and the inbox as ONE slim entry, `InboxEntry` (`unified_inbox.dart`: icon · "Inbox" · "3 to do · 1 overdue" · the to-do count · chevron → `InboxScreen`; its counts are `inbox_counts` / the organization's `todo` block of `/me/home`, never fewer than the preview rows, `inboxEntryCounts`; drawn only while the inbox holds a to-do, an announcement or an offer, so a fresh account shows no empty door; `InboxEntryCard` loads its own counts from `/me/inbox` where there is no `/me/home`: the parent's Children tab, an older server). The rows themselves live on the inbox page only. No "This week" (the schedule page has it) and no separate live card that repeats Today: the teacher's "Enter room" sits on the running row. Type: section titles 16 w600 without an accent bar, rows w500, meta w400, never w800 / w900. The teacher home's header ends with "Go live" (D-091, `lib/features/teacher/home/go_live.dart` pure + `go_live_sheet.dart`: course → the session scheduled now or a new one → Record → `PreJoinPage` (the teacher presses Join there, D-106) on the existing `POST /sessions` + `/live-sessions/start`; "Return to live" while a room of mine runs; kill switch `teacher.quick_live`; it loads nothing until tapped). The signed-in home's data is ONE call, `GET /api/v1/me/home`, loaded and cached by `MeHomeService.instance` (`lib/core/home/me_home.dart`: today / upcoming, attention, inbox preview, org overview, the teacher block; an older server's bare 404 falls back to composing it from the separate calls, so screens keep one code path). Badge counts for tabs and sections come from ONE call, `GET /api/v1/me/attention`, kept by `AttentionService.instance` (`lib/core/attention/`): it refreshes on the live event `attention_changed` and the `*_updated` events, on resume and route change, and polls as a fallback (60 s, 5 min while the live stream is connected), only while something listens. Draw a count with `AttentionBadge(tabKey: AttentionTabs.x, orgId:, child:)` (`lib/design/attention_badge.dart`); tapping opens the item's deep link. A new tab key is added in `AttentionTabs` AND in the server's `TABS` (`../back/services/attention_service.py`). Density rules (UX-home): sections are `HomeSection` (the title folds / unfolds it, remembered per user and section by `HomeFolds`; a section with nothing in it passes `empty:` and starts folded with one line such as "No classes today · Next: …", the choice kept per state, an explicit one wins), the agenda is compact by default (`HomeAgenda`: one line per item, live first via `homeAgendaFocus`, 3 + "Show all"; the running row is tinted with "Ends in 50 min · room", else the next says "Starts in …" — no role draws a separate "next up" hero that repeats "Today"), `HomeActionCard` draws icon · count · label only (the description is its tooltip / screen-reader hint), a "Needs you" strip with every count at zero is not drawn, and the greeting's subtitle is the day in one line (`homeDaySummary`). **Live now:** `/me/home` carries `live_now[]` (rooms live right now the person may join as an invitee: an active run of an enrolled course · an online meeting whose room is open); `MeHomeService.liveNow` follows `session_live` / `meeting_live` (an end drops the room at once, then one reload; an older server without `live_now` shows what the events announced), the teacher home's `TeacherHomeProvider.liveNow` the same, and `HomeLiveNow` (`lib/features/student/home/home_live.dart`) draws `HomeLiveBanner` on the student, instructor and org-member homes — Join opens the pre-join page, where the person presses Join (`openCourseLiveRoom` in `course_live_join.dart` / `openMeetingRoom`).
