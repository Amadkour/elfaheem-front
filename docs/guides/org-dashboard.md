# Organization dashboard (D-103)

The Organization Dashboard facts (D-103); the root `CLAUDE.md` keeps a summary, the rest of the organization notes are in `lib/features/org/CLAUDE.md`. Keep this file in step with the code.

**Organization dashboard (D-103, spec `docs/backend/org-dashboard-spec.md`, server routes under `/api/v1/org`)** — every org page has one anatomy. The header is `OrgPageHeader` (`org_page_header.dart`; the shell's top bar is off): title · ONE primary action · Search · Refresh ("Updated …" under the title) · calendar · messages · assistant · bell · help · the context switcher · the focus toggle last; from 600 px it is one row on the shell's own gradient and the page a sheet under it (`OrgPageFrame`, D-570). A page pushed on top wears `OrgPushedPage` (Back first, its own refresh, closed when another organization is chosen); a screen a student or a deep link may also open wears it only when `orgUsesDashboardHeader(context, orgId)`, else keeps its old app bar. A page with its own loader calls `OrgPageRefresh.register(context, _reload)` in `initState`, `reportUpdated(context, at)` after each load and `unregister` in `dispose` (else Refresh re-keys it). Under the header, `org_page_kit.dart`: `OrgPageBody` (one primary action — a filled button on wide, ONE FAB on phones — at most one search and one filter, More ⋯; cards, never wide tables on phones), `OrgFilterButton`, `OrgMoreMenu`, `OrgSegmented`, `OrgPartPicker`, `OrgSectionChips`; sizes from `app_tokens.dart`.
- Home (`lib/features/org/home/`, pure `org_home_logic.dart`; section order from the dashboard's `layout`): Needs your attention (`tasks` in `GET …/dashboard`, the list `GET /orgs/{id}/tasks`, one-tap `POST …/tasks/{task_id}/{action}` `{reason, version}` through the optimistic `OrgTaskQueue`, 409 `already_decided` / 404 `task_not_found`; the server audits it with `meta.via = "quick_actions"`) · My departments (a department page shows only the server's `departments[].tabs`, their view / insert / update levels hide Add / Edit) · Insights (`lib/features/org/insights/`, `GET /orgs/{id}/insights`, aggregates only — never a student's row; only with `can_insights`; lazy, fetched in parallel with the dashboard call; kill switch `org.insights`).
- Command palette (`org_command_palette*.dart`): Ctrl+K / ⌘K via `AppCommandPaletteScope` (`app_keyboard.dart`) or the header's Search; pages matched in the app, departments / people from `GET /orgs/{id}/search` (q ≥ 2, 250 ms debounce); kill switch `org.search`.
- Access: students get 403 `student_forbidden` (dashboard / search only); the live event `org_access_changed` or a 403 `org_forbidden` / `student_forbidden` reloads `/mine?members=1` and the sections.
