# Course lists, course page, course profile

Moved verbatim from the root `CLAUDE.md` (which keeps a short summary and the rules a session must never miss). Keep this file in step with the code.

**Course lists** — the student's My courses and the teacher's My Courses draw ONE card, `CourseListCard` (`lib/features/shared/course/course_list_card.dart`, D-102): a row on phones, a 16:9 tile grid from 600 px; the cover carries at most two overlays (Live / Recorded lessons or Draft / Published chip; heart or ⋮); title 2 lines w600, one meta line (`CourseOrgBadge` leads it in a mixed list), a role footer (progress % · price via `coursePriceLabel` · students / sessions / rating). Prices are always `coursePriceLabel` ("EGP 450" in English, "450 ج.م" in Arabic). Header = scope chips / banner + search + segmented filter carrying the counts. Tests: `test/ui/course_list_card_layout_test.dart`, renders `test/visual/course_lists_golden_test.dart`.

**Course page (`lib/features/shared/course/course_space/`)** — `CourseSpace` is THE course page, shared by the student's course details (`course_detail_screen.dart` + `course_detail_parts.dart`) and the teacher's course studio (`sessions_screen.dart` + `teacher_course_parts.dart`). It takes plain values in slots (hero · spotlight cards · quick actions · tabs, only the active one built · `aside` on wide · `bottomBar` on narrow; the header comment of `course_space.dart` has the phone / desktop layouts) and reads no provider; each role's screen maps its own data into it. A spotlight card with nothing to say returns `SizedBox.shrink()`. **The header (D-940 – D-943)** is one block (`AppBlock(wash: true)`): chips · title (`courseHeroTitleStyle`, never the display size) · one-line subtitle · teacher · progress · the role's ONE call to action (`CourseSpaceHeroData.cta`: teacher New session + Edit + Share, enrolled student Continue, visitor / guest price + Enroll via `courseBuyCta`; left out on a phone with a `bottomBar`, which carries it) · the stats as a grid (a tappable stat is a chip with a chevron; the rating is a stat). The cover is framed at 16:9 and shown whole (`CourseCover`: contained over a blurred copy). Price, New session and Edit course appear once per page: no side card or shortcut repeats them. Tests: `test/ui/course_header_layout_test.dart`; renders `test/visual/course_header_golden_test.dart`. Sessions are ONE timeline for both roles, `course_sessions.dart` (plain values, D-102): numbered nodes on a line, states done / up next / live / locked / scheduled, one meta line (kind · AppTime date · length · files); student rows carry progress and Join / Start exam and fold a long completed start; teacher rows a ⋮ menu and reorder. A session title the server generated (`title_auto`) is shown in the reader's language (`sessionTitleOf`). Tests: `test/ui/course_space_layout_test.dart`, `course_detail_layout_test.dart`, `teacher_course_layout_test.dart`; renders in `test/visual/course_space_golden_test.dart`.

**Course profile (`lib/features/shared/course_profile/`)** — Since D-111 its parts are TABS of the one course page (`course_profile_hub.dart`: `CourseProfileHub` loads `GET /course-profile/{id}` lazily when a profile tab opens; `courseProfileTabs` gives the student Announcements · Progress · (Archive) and staff Announcements · Attendance · Team · Archive; `CoursePageLoader` is what `openCourseProfile`, `/course-profile` and `course_profile` notifications open). `CourseProfileScreen` remains only for an earlier run (read-only) and as the fallback. TAs work on sections/labs only unless the instructor grants more; archived courses are read-only. Backend: `../back/routers/course_profile_router.py` (incl. course announcements), test `tests/org_v2/e2e_course_profile.py`.
