# Course roadmap and recommendations

Moved verbatim from the root `CLAUDE.md` (which keeps a short summary and the rules a session must never miss). Keep this file in step with the code.

**Course roadmap + recommendations (`lib/features/courses/roadmap/`, D-120)** — personal accounts on personal courses ONLY: an account in an organization (org-admin / org-staff, or a live membership while organizations are on) gets neither, and an organization course has no roadmap (server: `../back/services/learning/access.py`, 403 `individual_only` / `org_course` / `feature_off`; app: `roadmapOrgAccount`, `roadmapHiddenError` draws nothing). `roadmap_api.dart` is the pure part (models, `RoadmapDraft`, API: `GET/PUT /api/v1/roadmap/courses/{id}`, `/me/recommendations`, `/me/learning-prefs`, `/me/journey`). The course page's "Path" tab (`roadmap_tab.dart`, both roles) draws ONE vertical path (`roadmap_path.dart`: previous → "You are here" → next in order with prerequisite ✓ / ○ chips) and the teacher's editor sheet (`roadmap_editor.dart`: next courses = the same `course_next_steps` as the course form, advisory prerequisites, level, topic words). The backend's hybrid engine (`../back/services/learning/scoring.py`, pure; `recs.py` caches per student) feeds "Recommended for you" on the profile (`recommendations.dart`, a reason per course, "Not interested", interests sheet); the teacher's path and the engine's list never mix. The student home has ONE journey card (`lib/features/student/home/home_journey.dart`) from `/me/home`'s `journey` (no request of its own; null → no card), swept by `AppShineBand` (`lib/design/app_shine.dart`, the attendance entry's band, parked by Reduce motion) → `JourneyPage`. What the lists do is reported in batches (`RecEventLog`) and the super admin reads it per reason and tunes the four weights on `AdminRecommendationsPage` (`lib/features/admin/admin_recs_page.dart`). For a personal course the course form links to the Path editor instead of its own next-courses field and never sends `next_course_ids` (it would undo the Path tab); level / topic words are in both. Kill switches `roadmap` · `roadmap.path` · `roadmap.recommendations` · `roadmap.journey` · `course.enroll_roadmap` · `admin.recommendations` (`roadmapOff` also checks the root). Tests: `test/org/roadmap_test.dart`, `test/ui/roadmap_layout_test.dart`; backend `tests/org_v2/e2e_learning_roadmap.py`, `recs_unit.py`.
