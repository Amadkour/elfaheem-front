## Privacy leaks today

Student-facing endpoints or payloads that return other students' names, avatars, ids, counts or presence:

1. **LiveKit student token sees everyone**: `features/live/LiveKit_service.py:336-376` (`can_subscribe=True`, `can_publish_data=True`, no `hidden`), identity `student_<id>` and `with_name(student.name)` + `image_url` metadata (`:365-378`, `:2693-2706`). Same in guest tokens (`:418-437`), meeting tokens (`features/home/calendar_service.py:736`) and `features/home/dashboard_service.py:327`. Route: `GET /live-sessions/{id}/join` (`features/live/api/online_sessions.py:118-152`).
2. **In-room data channel and typing**: students can publish data to the room (`LiveKit_service.py:372`), so hand-raise/chat is peer-visible; `chat_typing` event carries other users' `user_id` and `name` (`features/chat/realtime.py:95-100`).
3. **Course group chat with student authors and member list**: `GET /chat/conversations/{id}/members` (`features/chat/api/chat_router.py:122` -> `features/chat/service.py:497`), group membership `features/chat/rules.py:123-131`, group creation `service.py:181, 433`.
4. **Student-student direct links in a shared course** (`rules.py:8, 160-181`; `GET /chat/contacts` `chat_router.py:172`, `service.py:712-779`, suggestions `people.py`) when the teacher/org sets `student_dm`: this tells a student who is in his course.
5. **Course counts on public and student routes**: `students_count` / `enrollments_count` in `CourseResponse` (`data/schemas.py:435-439, 499-502`), computed in `features/courses/course_service.py:1005-1011, 1103-1104`, served by `GET /courses` and `/courses/{id}` (`features/courses/api/courses.py:181, 230`), `/my-enrolled-courses` (`:735`).
6. **Package seat counts**: `seats_taken`, `waitlist_count`, `max_students` in `features/packages/package_service.py:161-167` (`GET /packages`, `/packages/{id}`, `/me/packages`: `packages_router.py:91-171`).
7. **Ratings expose `student_id`**: `RateResponse` (`data/schemas.py:648-655`), unauthenticated `GET /courses/{id}/ratings` etc. (`features/courses/api/ratings.py:24-48`). The design allows first name + grade only.
8. **Leaderboards**: real name "Ahmed H." (`features/games/games_service.py:696-701, 754`), org-scoped board (`:727-745`, `GET /games/{id}/leaderboard` `games_router.py:160`), weekly champions (`features/games/champions.py:262-284`), challenge participants (`challenges.py:99, 113`), ghost (`level_stats.py:118`), per-class board with player counts (`challenges.py:189-218`, `GET /games/class-board`).
