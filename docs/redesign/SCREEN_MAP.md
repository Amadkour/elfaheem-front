- **URL**: under `docs/redesign/design/`. Phone = 390 px, web = 1360 px, same URL.
- **Flutter today**: paths are under `lib/features/` unless they start with `lib/` or `landing/`. In the admin and super admin sections a bare `admin_*.dart` is in `lib/features/admin/`.

- Rows whose note starts with "Checked" were opened in the code or the design in this phase. Other `exists` rows still come from file names: the owning group confirms them when it starts.
